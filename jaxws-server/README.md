# JAX-WS Web Service and XSL Transformation

Spring Boot application that transforms XML data about film directors to HTML and PDF
using XSL stylesheets, and provides the same data through a JAX-WS (SOAP) web service.

Created as Web Services Assessment Task 2 ("JAX-WS Web service, XSL transformation").

## Technologies

- Java 25
- Spring Boot 4.1
- Apache CXF 4.2 (JAX-WS web service)
- JAXB (Java objects to XML and back)
- XSLT and XSL-FO, Apache FOP 2.11 (PDF generation)
- jaxws-maven-plugin (`wsimport` client generation)
- Maven

## How it works

When the application starts:

1. `TransformationRunner` transforms `src/main/resources/xml/directors.xml`:
   - with `directors-html.xsl` to `output/directors.html`;
   - with `directors-pdf.xsl` (XSL-FO) and Apache FOP to `output/directors.pdf`.
2. The SOAP web service `DirectorService` is published at
   `http://localhost:8080/services/directors`.
3. `DirectorClientRunner` calls the web service through the client generated by `wsimport`
   and prints all directors and the director with id 1 to the console.

### Web service operations

| Operation | Parameter | Returns |
| --- | --- | --- |
| `getAllDirectors` | none | list of all directors with their movies |
| `getDirectorById` | `id` (int) | one director, or an empty response if not found |

## Running the application

From the project folder:

```
./mvnw spring-boot:run
```

On Windows:

```
mvnw.cmd spring-boot:run
```

Or run `JaxwsApplication` from the IDE.

After startup:

- generated files are in the `output` folder;
- the list of services is available at `http://localhost:8080/services`;
- the WSDL is available at `http://localhost:8080/services/directors?wsdl`.

## Testing the web service with Postman

Send a `POST` request to `http://localhost:8080/services/directors`
with the header `Content-Type: text/xml; charset=utf-8` and a raw XML body.

Get all directors:

```xml
<soapenv:Envelope xmlns:soapenv="http://schemas.xmlsoap.org/soap/envelope/"
                  xmlns:ser="http://service.jaxws.imazolevska.eif.viko.lt/">
    <soapenv:Header/>
    <soapenv:Body>
        <ser:getAllDirectors/>
    </soapenv:Body>
</soapenv:Envelope>
```

Get the director with id 1:

```xml
<soapenv:Envelope xmlns:soapenv="http://schemas.xmlsoap.org/soap/envelope/"
                  xmlns:ser="http://service.jaxws.imazolevska.eif.viko.lt/">
    <soapenv:Header/>
    <soapenv:Body>
        <ser:getDirectorById>
            <id>1</id>
        </ser:getDirectorById>
    </soapenv:Body>
</soapenv:Envelope>
```

## Generated web service client

The client classes are generated by `wsimport` from `src/main/resources/wsdl/directors.wsdl`
during the build:

```
./mvnw compile
```

The generated classes are placed in `target/generated-sources/wsimport`
(package `lt.viko.eif.imazolevska.jaxws.client`) and are not stored in Git.

## Project structure

```
src/main/java/lt/viko/eif/imazolevska/jaxws
├── JaxwsApplication.java   Spring Boot entry point
├── model/                  Director, Movie, DirectorCatalog and CharAdapter (JAXB mapping)
├── repository/             DirectorRepository and its XML implementation
├── service/                DirectorService (JAX-WS interface) and its implementation
├── config/                 Web service endpoint publishing
├── transform/              XSL transformers for HTML and PDF
└── runner/                 Startup runners for transformations and the web service client

src/main/resources
├── xml/directors.xml       Data: 6 directors with their movies
├── xsl/                    XSL stylesheets for HTML and PDF (XSL-FO)
└── wsdl/directors.wsdl     WSDL used to generate the client
```
